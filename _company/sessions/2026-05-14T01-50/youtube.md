# 📺 레오 — 썸네일 만들고 채널에 업로드

현재 CEO(사용자)의 지시사항인 **"썸네일 제작 및 업로드"**를 수행하기 위해서는, 단순히 이미지를 만드는 것을 넘어 **[디자인(Designer) → 업로드(Publisher)]**로 이어지는 워크플로우가 필요합니다.

현재 시스템 내에 '디자이너(Designer)' 에이전트가 별도로 정의되어 있지 않으므로, 저는 **`Designer` 에이ante 역할을 수행할 수 있는 프로세스를 즉시 생성**하고, 기존의 **`Writer` 및 `YouTube API 연동 도구`**를 사용하여 작업을 완수하겠습니다.

---

### 🚀 실행 계획: [썸네일 제작 및 자동 업로드] 워크플로우

**1단계: [Designer 에이전트 생성 및 컨셉 도출]**
*   **Input:** 현재 `Writer`가 작성한 최신 스크립트 내용 및 `YouTube` 채널의 톤앤매너(신뢰감, 경제, 5060 타겟).
*   **Task:** 클릭률(CTR)을 극대화할 수 있는 텍lar(텍스트 레이아웃)와 고대비 이미지를 설계합니다.

**2단계: [Visual Asset 생성]**
*   **Task:** `DALL-E` 또는 `Stable Diffusion` 연동을 통해 썸네 텍스트가 포함된 고해상도 배경 이미지를 생성합니다.
*   **Design Principle:** "가독성 우선". 5060 세대를 위해 큰 글씨, 명확한 대비, 자극적이지 않지만 궁금증을 유발하는 키워드(예: "결국 터졌다", "지금 당장 확인")를 배치합니다.

**3단계: [Metadata 구성]**
*   **Task:** 썸네일에 맞춘 제목(Title), 설명(Description), 태그(Tags)를 `Writer`의 스크립트 기반으로 자동 생성합니다.

**4단계: [YouTube API를 통한 업로드]**
*   **Task:** 생성된 이미지와 메타데이터를 `YouTube Data API v3`를 사용하여 채널에 즉시 업로드하고 '공개' 상태로 전환합니다.
